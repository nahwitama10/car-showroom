# Aurora Motors - EV Showroom

Static site (HTML/CSS/JS): catalog filters, compare, favorites, finance calculator, dark/light theme.

## Structure
```n index.html
 css/style.css
 js/data.js  (car data)
 assets/img/  (photos)
 js/app.js
 vercel.json
```n
## Run locally
`npx serve .` or open `index.html`

## Deploy
1. `git init; git add .; git commit -m 'Initial commit'`2. Create a GitHub repo, then `git remote add origin <url>; git branch -M main; git push -u origin main`
3. On vercel.com: Add New > Project > import the repo. Framework Preset: **Other**, no build command, output directory blank. Deploy.
